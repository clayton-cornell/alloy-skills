# Accuracy checklist — routing index

- Component reference pages (`reference/components/*.md`, including
  Example/config-snippet syntax validation and Changelog drift) →
  `references/accuracy-checklist-components.md`
- CLI reference pages (`reference/cli/*.md`) → `references/accuracy-checklist-cli.md`
- Syntax/language and stdlib pages (`get-started/syntax.md`,
  `get-started/expressions/*`, `reference/stdlib/*.md`) →
  `references/accuracy-checklist-syntax.md`
- Packaging/deployment pages (`set-up/install/*.md`, `set-up/run/*.md`,
  `configure/*.md`) → `references/accuracy-checklist-packaging.md`
- Log-message text (`troubleshoot/debug.md` and similar, whenever a page
  quotes literal `msg="..."` output) → `references/accuracy-checklist-other.md`

`references/technical-verification.md` (risk-tiered triage order) applies
regardless of category — read it alongside whichever file above is relevant.

SKILL.md's Step 0 already tells you which category a given topic falls into
— go straight to the matching file above rather than opening this one for
content.
