# Mapping doc topics to source — routing index

- Component reference pages (`reference/components/*.md`) → `references/source-mapping-components.md`
- CLI reference pages (`reference/cli/*.md`, including the `otel.md` and
  `environment-variables.md` special cases) → `references/source-mapping-cli.md`
- Core syntax/language pages (`get-started/syntax.md`, `get-started/expressions/*`,
  `reference/stdlib/*.md`) → `references/source-mapping-syntax.md`
- Packaging/deployment pages (`set-up/install/*.md`, `set-up/run/*.md`,
  `configure/*.md`) → `references/source-mapping-packaging.md`
- Everything else (generic conceptual pages, log-message-text locations) →
  `references/source-mapping-other.md`
